# TLC Café

A modern, high-performance website for **TLC Café**, built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features

- **Cinematic Experience**: Immersive typography, smooth animations, and tailored imagery.
- **Editorial Brand Aesthetic**: Tailored color palette, responsive navigation with dynamic scroll states, and ambient visual effects.
- **Interactive Menu & Gallery**: Interactive category tabs and responsive media carousels.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide Icons](https://lucide.dev/)
